# 🧠 Website Kuis Online Sederhana

## 📖 Deskripsi Project
Project ini merupakan **website kuis online sederhana** dengan materi seputar **HTML, CSS, JavaScript, dan DOM**.  
Website dibuat untuk menguji pemahaman dasar pengguna melalui soal pilihan ganda.

Project dikembangkan menggunakan **HTML, CSS, dan JavaScript murni (Vanilla JS)** tanpa framework, backend, atau database.

---

## 🎯 Fitur Utama
- Menampilkan minimal 5 soal pilihan ganda
- Setiap soal memiliki 4 opsi jawaban
- Validasi jawaban menggunakan JavaScript
- Perhitungan skor otomatis
- Skor +20 untuk setiap jawaban benar
- Menampilkan hasil kuis (Lulus / Tidak Lulus)
- Tombol ulangi kuis
- Manipulasi DOM tanpa reload halaman

---

## 🧠 Alur Logika / Algoritma
1. Sistem menampilkan soal kuis dan pilihan jawaban.
2. Pengguna memilih jawaban dan menekan tombol **Selesai Kuis**.
3. JavaScript memeriksa jawaban pengguna.
4. Setiap jawaban benar mendapatkan skor 20 poin.
5. Skor akhir dihitung dan ditampilkan.
6. Jika skor ≥ 70 → **Lulus**, jika < 70 → **Tidak Lulus**.
7. Tombol **Ulangi Kuis** digunakan untuk mengulang kuis.

---
